# Day 20 – Train Test Split

## Why split data?

To evaluate model performance on unseen data and avoid overfitting.

## Training Set

Used to learn parameters and fit the model.

## Test Set

Used only to evaluate performance after training.

## Typical split

- 80% training
- 20% testing

These ratios are common choices; 70/30 or 75/25 are also used depending on dataset size.
